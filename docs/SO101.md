# SO101 机械臂支持（进行中）

## 双臂硬件信息（已读取，2026-10-30）

两套 SO101（各为 leader + follower）分两次接到 Cobot Magic 主机上读取（USB 口不够），再合成双臂。
**双臂不在这台机器上搭建**：仓库按串口序列号描述硬件，克隆到目标主机后重新探测即可。

```bash
bash env/install_all.sh --only 06                      # so101/.venv：pyserial + feetech-servo-sdk，无需 ROS/GPU
so101/.venv/bin/python so101/probe.py --out so101/probes/set1.json     # 只接第一套时
so101/.venv/bin/python so101/probe.py --out so101/probes/set2.json     # 换接第二套后
so101/.venv/bin/python so101/probe.py --merge so101/probes/set1.json so101/probes/set2.json \
    --left set1 --right set2 --out so101/dual_arm.yaml
```

- `probe.py` 只读，不向舵机写任何数据；用 `/dev/serial/by-id`（USB 序列号）标识串口，主从按供电电压判断（leader≈5 V，follower≈12 V）。
- 两套均为 6 个 STS3215（ID 1–6，1 Mbps，固件 3.10）。已有读数见 `so101/probes/`，示例结果见 `so101/dual_arm.yaml`。
- 左右分配（set1=左，set2=右）**待确认**；标定文件在目标主机上用 LeRobot 标定流程现场生成，不随仓库提供。
- 目标主机需要在 `dialout` 组。相机配置待填。

## 数据采集 → π0.5 训练 → 推理（已实现，mock 验证通过，未在双臂真机上验证）

所有命令在仓库根目录执行；机器人所在主机装 `env/install_all.sh --only 03`（openpi 环境，含 lerobot 0.1.0）和 `--only 06`。

```bash
# 0. 把 so101/dual_arm.yaml 里的 cam_* device 改成本机相机（/dev/v4l/by-id/...），port_by_id 按 probe.py 的结果核对
# 1. 标定（每条臂一次，按提示摆姿势；文件写到 so101/calibration/，不入库）
openpi/.venv/bin/python so101/cli.py calibrate
# 2. 遥操作自检、录制（左右 leader 带动左右 follower，录成 LeRobot v2.1：12 维状态/动作 + 三路相机）
openpi/.venv/bin/python so101/cli.py teleoperate
openpi/.venv/bin/python so101/cli.py record --task "<任务描述>" --episodes 50 --episode-time 60 \
    --root ~/rlt_data/lerobot_data/so101_dual            # → 键：右箭头结束本条，左箭头重录，Esc 停止
ln -s ~/rlt_data/lerobot_data openpi/lerobot_data          # 训练配置读 ./lerobot_data/so101_dual
# 3. 归一化统计（直接读 parquet，写入两个训练配置的 assets/）
cd openpi && .venv/bin/python scripts/compute_so101_parquet_norm_stats.py --dataset-root lerobot_data/so101_dual
# 4. 训练：pi05_so101_dual（全参，多卡）或 pi05_so101_dual_lora（单张 24 GB）
XLA_PYTHON_CLIENT_MEM_FRACTION=0.9 .venv/bin/python scripts/train.py pi05_so101_dual_lora --exp-name=so101_v1 --no-wandb-enabled
# 5. 推理：GPU 主机起服务，机器人主机连接
.venv/bin/python scripts/serve_policy.py --port 6006 policy:checkpoint --policy.config pi05_so101_dual_lora --policy.dir checkpoints/pi05_so101_dual_lora/so101_v1/<step>
openpi/.venv/bin/python so101/infer.py --host <GPU 主机> --port 6006 --task "<任务描述>"
```

要点：
- 状态/动作为 12 维 `[左臂 6, 右臂 6]`（每臂 shoulder_pan…wrist_roll + gripper，LeRobot 标定后的角度，夹爪 0–100）。
  动作训练时对 10 个关节取相对当前状态的增量，两个夹爪保持绝对值（`LeRobotSo101DataConfig`）。
- 相机名固定为 `cam_high / cam_left_wrist / cam_right_wrist`，其中缺少的腕部相机会被遮罩。
- `infer.py` 每次取 `--execute`（默认 25）步动作后重新规划，每步关节增量受 `--max-relative-target`（默认 10°）限制；
  先用 `--mock --dummy` 检查链路。
- 已验证：mock 双臂录制 → parquet/视频 → 归一化 → `pi05_so101_dual_lora` 3 步训练（loss 0.15→0.22，仅验证链路通）→ 单元测试；
  `infer.py --mock --dummy`。**未验证：** 真机标定、真实相机、真实任务数据上的训练效果。
